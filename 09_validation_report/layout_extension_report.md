# 新增条款版式测试报告

生成日期：2026-09-23

## 测试范围

本次新增两份自行选择的保险条款：

- 新华人寿《E 增福优享版终身寿险（互联网）》：7 页。
- 太保鑫相伴（2025）终身寿险：10 页。

本报告记录 PDF 解析、章节切分、Prompt 生成和结构校验结果。两款产品均已进入五产品、13字段、65行 Gold。

## 发现并修复的问题

### 1. 多栏目录被误识别为正文

太保鑫相伴第1页含阅读指引和三栏目录。PDF 文本层会交错输出目录项，旧规则可能把目录编号当作正式条款。

修复后正文从第2页开始，共52个章节，多栏目录不再进入模型正文上下文。

### 2. 复合页脚混入正文

新华 PDF 后附《个人保险基本条款第三版》，其页脚采用“个人保险基本条款第三版第 N 页”的形式。旧规则只处理独立页码，导致该页脚进入 clean 和 canonical 文本。

修复后，页面边缘不超过 40 个字符且以“第 N 页”结尾的行按页码元数据清理。重新提取后未发现上述复合页脚残留。

### 3. 低文本密度误报扫描风险

本轮两份正式 PDF 均存在可用文本层，没有启用 OCR；低文本密度告警仍需结合页面渲染判断，不能直接等同于扫描件。

本次没有启用 OCR。低文本密度告警继续保留，人工复核结论单独记录，避免把字符数少直接等同于扫描件。

### 4. 窄标题栏与正文同行

太保正文含窄标题栏与正文相邻的排版。切分器使用完整标题优先和受控前缀恢复，避免标题与正文粘连。

- 2.1 基本保险金额
- 2.2 有效保险金额
- 2.5.1 身故保险金或全残保险金
- 2.5.2 身故保险金或全残保险金
- 2.5.3 意外身故或意外全残豁免保险费

## 仍需人工复核
